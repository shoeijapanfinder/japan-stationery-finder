# Japan Stationery Finder

Static GitHub Pages site for Japan-exclusive, store-exclusive and hard-to-find stationery.

## Files
- `index.html`
- `style.css`
- `script.js`
- `products.json`

## Deploy
Upload these files to a GitHub repository and enable GitHub Pages from the repository settings.

## Data
The site uses the curated 29-product master dataset. Product claims should be re-checked before expanding the dataset, especially exclusivity and shipping status.
